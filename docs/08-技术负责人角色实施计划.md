# 技术负责人角色与人员管理功能实施计划

## Context

当前系统有4种角色：产品经理(product)、开发人员(developer)、测试人员(tester)、管理员(admin)。故事创建后直接进入backlog状态，没有审批流程。产品经理负责创建故事，可以分配给开发人员或开发人员自行领取。

**本次变更目标：**
1. 新增"技术负责人(tech_lead)"角色
2. 实现故事审批流程：产品经理创建 → 技术负责人审批 → 分配给开发
3. 技术负责人拥有系统级视角，可查看和管理所有项目的故事
4. 增加人员管理界面，支持工作负载统计视图
