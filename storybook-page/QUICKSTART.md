# Storybook 前端快速启动指南

## 启动步骤

> 前提：后端 API 服务已在 `http://localhost:8080` 运行（参见根目录 [README](../README.md)）。

### 1. 安装依赖

```bash
cd storybook-page
pnpm install
```

### 2. 配置环境变量

```bash
cp .env.example .env
```

### 3. 启动开发服务器

```bash
pnpm run dev
```

服务器将在 http://localhost:3000 启动。

### 4. 访问应用

打开浏览器访问 http://localhost:3000

## 测试账号

你可以：

1. 点击"立即注册"创建新账号
2. 或使用后端 `bootstrap-admin` 命令创建的管理员账号登录

## 核心功能演示流程

1. **注册/登录** — 访问首页，点击"立即注册"创建账号，选择角色（产品/开发/测试）
2. **创建项目** — 登录后进入项目列表，点击"+ 新建项目"
3. **看板操作** — 进入项目详情 → 看板标签，拖拽故事卡片到不同列，实时看到状态更新
4. **创建故事** — 在看板页面点击"+ 创建故事"，填写故事信息、添加验收标准
5. **故事详情** — 查看完整故事信息，勾选验收标准，查看活动时间轴
6. **个人工作台** — 点击顶部用户名选择"个人工作台"，查看我的故事和统计数据
