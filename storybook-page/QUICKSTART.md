# Storybook 前端快速启动指南

## 🚀 启动步骤

### 1. 确保后端服务运行

首先确保后端 API 服务在 `http://localhost:8080` 运行。

### 2. 安装依赖

```bash
cd storybook-page
pnpm install
```

### 3. 配置环境变量

```bash
cp .env.example .env
```

### 4. 启动开发服务器

```bash
pnpm run dev
```

服务器将在 http://localhost:3000 启动。

### 5. 访问应用

打开浏览器访问 http://localhost:3000

## 🔑 测试账号

你可以：

1. 点击"立即注册"创建新账号
2. 或使用后端创建的测试账号登录

## ✨ 核心功能演示流程

### 完整操作流程：

1. **注册/登录**
   - 访问 http://localhost:3000
   - 点击"立即注册"创建账号
   - 选择角色（产品/开发/测试）

2. **创建项目**
   - 登录后进入项目列表
   - 点击"+ 新建项目"
   - 填写项目信息并创建

3. **看板操作**
   - 进入项目详情
   - 点击"看板"标签
   - 拖拽故事卡片到不同列
   - 实时看到状态更新

4. **创建故事**
   - 在看板页面点击"+ 创建故事"
   - 填写故事信息、添加验收标准
   - 创建后自动跳转到故事详情

5. **故事详情**
   - 查看完整故事信息
   - 勾选验收标准
   - 查看活动时间轴

6. **个人工作台**
   - 点击顶部用户名选择"个人工作台"
   - 查看我的故事和统计数据

## 🎨 设计特色

- **精致专业主义**：深海蓝 + 薄荷绿配色
- **流畅动画**：200-300ms 微动效
- **玻璃拟态**：看板列背景模糊效果
- **环形进度条**：AC完成度可视化
- **实时更新**：WebSocket 推送

## 🔧 技术亮点

- React 19 + TypeScript
- Zustand 状态管理
- @dnd-kit 拖拽交互
- Tailwind CSS 4 主题系统
- WebSocket 实时通信

## 📝 注意事项

- 确保 CORS 配置正确（前后端同源或配置代理）
- JWT Token 自动刷新机制已集成
- WebSocket 连接会自动重连
- 所有 API 请求都有错误处理
